# מצב מימוש — גרסה 0.1

זהו מסלול ליבה עובד, לא מסירת כל הפרויקט. הבדיקות מתייחסות ליכולות שמומשו בלבד.

## אימות שבוצע

- יצירת Prisma Client 7 עם adapter-pg, מיגרציות SQL ושמירה ב־PostgreSQL אמיתי.
- build הכולל TypeScript ובניית React/Vite.
- 18 בדיקות מנוע: אכשרה, תאריכים, השתתפות לאירוע, החזר, תקרות, החרגות והשעה.
- 17 בדיקות API: התחברות/CSRF, נתוני לקוח, תאריך לא תקין, הצעה חופפת, idempotency בהפעלה, optimistic concurrency, גרסת מוצר, משימות, השעיה, אישורי תביעה מקבילים, תשלום כפול, גבייה, הרשאות, ביטול ופניות, חיתום ידני עם החרגה וחתימה מדומה.
- בדיקת Playwright מלאה בעברית כולל הפעלת פוליסה, דחייה באכשרה, היסטוריה ותצוגת/הורדת מסמך PDF.
- seed בסיסי חוזר ללא מחיקת נתוני משתמש.
- Docker: בניית API ו־web, הפעלה מול volume חדש, התחברות וקריאת נתונים דרך Nginx, הפקת PDF בקונטיינר וכניסה לממשק בדפדפן. נבדק על Linux בענן; לא נבדק עדיין על מחשב Windows.

## מה עדיין חסר מהאפיון המלא

| תחום | עבודה שנותרה |
|---|---|
| לקוחות וחיות | כתובות מרובות, נציגים מורשים, אנשי קשר, עריכת חיה, רשומות רפואיות ותרופות מסודרות, העלאת קבצים |
| מוצרים וחיתום | קטלוג כיסויים נפרד, טיוטת מוצר/פרסום, גילי כניסה ניתנים לעריכה, כללי סיכון כלליים, תוספות פרמיה והחרגות רפואיות פרטניות |
| הצטרפות | שאלון רב־שלבי, הצהרת בריאות נפרדת, הצעה מוגבלת בזמן, אמצעי תשלום מדומים במסד |
| פוליסות | חידוש מקושר, שינוי מסלול ופרמיה במועד תחולה, הרחבות, גרסאות תקופתיות ומנגנון סיום אוטומטי |
| תביעות | צירוף חשבוניות/קבצים, תיקון שורות, פתיחה מחדש, ערעור, שינוי החלטה, יוזם ומאשר נפרדים |
| כספים | גבייה חודשית, לוח חיובים, ספר חשבונות כפול מאוזן, תיקוני חיובים, ביצוע החזר, היפוך תשלום והתאמות |
| מסמכים | כלל סוגי הטפסים, תבניות וגרסאות מנוהלות, hash ואחסון PDF סופי, worker/outbox ויכולת retry |
| שירות | הקצאה והעברה לעובד אחר, תורי מחלקות, הסלמה ותיעוד שיחות מובנה |
| הרשאות | ניהול עובדים, תפקידים והרשאות מפורטות במסד, ספי סמכות מותאמים, שחזור סיסמה ומדיניות sessions מלאה |
| ביקורת | רישום כישלונות עסקיים, צמצום/מיסוך מידע רגיש, מדיניות שמירה ומניעת שינוי ביומן ברמת DB |
| דוחות | זמני טיפול, ביצועי עובדים, יחס תביעות לפרמיות, חריגים וייצוא |
| איכות | בדיקות לכל מסלולי החיתום והחתימה, כשל PDF, בדיקות שחזור, נגישות, התאמה ל־Windows בפועל |
| מחקר | אימות מקורות ישראליים ותיעוד מדויק של מקורות ותנאים לפני שימוש אמיתי |

## סדר המשך

1. השלמת שינויי פוליסה/חידוש עם תנאים היסטוריים ופרמיות לפי מועד תחולה.
2. תיקון, ערעור והיפוך תביעות ותשלומים תוך שימור יתרות ומניעת כפל.
3. הרחבת כספים לחיובים חודשיים, החזרים וספר חשבונות מאוזן.
4. קבצים, תבניות מסמכים, עובד מסמכים ו־outbox.
5. עובדים, RBAC במסד, תורי מחלקות ודוחות מתקדמים.
6. בדיקות לכל האפיון, אבטחה, נגישות ואימות התקנה במחשב Windows.

הדוחות הנוכחיים הם תפעוליים; אין לייחס להם מעמד של הנהלת חשבונות מלאה או דיווח רגולטורי.
