# BITUCHA 3.0 — ENTERPRISE PET INSURANCE CORE
## MASTER IMPLEMENTATION DIRECTIVE — FULL SYSTEM COMPLETION

### הוראת על

אתה משמש כצוות פיתוח תוכנה ארגוני מלא: ארכיטקט מערכת, מפתח Backend, מפתח Frontend, מהנדס מסדי נתונים, מנתח מערכות ביטוח, מהנדס QA, מעצב UX ומומחה אבטחת מידע.

משימתך היא להפוך את BITUCHA למערכת ליבה ארגונית רחבת היקף לניהול חברת ביטוח לחיות מחמד, עם תהליכים עסקיים עמוקים, מסכים מקצועיים, מנועי חישוב, מסמכים, הרשאות, תורים, אישורים, נתונים והיסטוריה.

**אין להסתפק ביצירת אבטיפוס, מערכת דמו שטחית, מסכים יפים או מסמכי תכנון. נדרש מימוש תוכנה אמיתי, מלא וניתן לבדיקה.**

Repository:
https://github.com/nehoraialush/bitucha

Working branch:
feature/enterprise-workflows

הפרויקט משתמש ב־React, TypeScript, NestJS, PostgreSQL, Prisma 7 ו־Docker.

יש לשמור על הארכיטקטורה הקיימת כאשר היא מתאימה, להרחיב אותה באופן מבוקר, ולשמר את כל המידע והיכולות הקיימות.

המערכת מיועדת כרגע לסימולציה מקצועית בלבד. כל הלקוחות, בעלי החיים, פרטי הרפואה, הכספים והחתימות יהיו בדויים. אין להציג את המערכת כמורשית לביטוח אמיתי, ואין להפעיל תשלומים אמיתיים או חתימות בעלות תוקף משפטי נטען.

# 25. בדיקות קבלה מחייבות

אין להחשיב מודול כמושלם בלי בדיקת מסלול מלא.

### מסלול A — הצטרפות

לקוח חדש → בעל חיים → שאלון רפואי → מסמכים → חיתום → הצעה → חתימה → תשלום מדומה → הפקת פוליסה → PDF.

### מסלול B — חידוש

פוליסה קיימת → בקשת חידוש → בדיקת הצהרות → תמחור → אישור → פוליסה חדשה מקושרת.

### מסלול C — תביעה

פוליסה פעילה → פתיחת תביעה → טיפולים וחשבוניות → בדיקת כיסוי → החלטה → תשלום מדומה → מסמך.

### מסלול D — התחייבות

בקשת טיפול עתידי → מסמכים → בדיקת זכאות → שריון → אישור → ניצול בתביעה.

### מסלול E — שינוי פוליסה

פוליסה פעילה → שינוי מסלול → בדיקת זכאות → חישוב הפרש פרמיה → אישור → נספח.

### מסלול F — כספים

חיוב → גבייה חלקית → חוב → הסדר → גבייה → התאמה → דוח.

### מסלול G — שירות

פנייה → זיהוי → טיפול → העברה → משימה → הסלמה → סגירה.

### מסלול H — וטרינר

מרפאה מורשית → בדיקת זכאות מוגבלת → בקשת התחייבות → מסמך → החלטה.

### מסלול I — הרשאות

עובד ללא הרשאה מנסה פעולה אסורה → השרת חוסם → אירוע ביקורת נשמר.

### מסלול J — שחזור

גיבוי מסד פיתוח → שחזור בסביבה מבודדת → אימות שלמות הנתונים.

יש להריץ בדיקות יחידה, API, אינטגרציה ו־Playwright.
