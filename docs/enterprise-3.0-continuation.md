# BITUCHA 3.0 — מצב ופקודת המשך

תאריך: 9 באוקטובר 2026. ענף: feature/enterprise-workflows. המערכת המלאה אינה מושלמת.

מקור מחייב: enterprise-3.0-requirements.md והנחיית המשתמש המאוחרת לגבי קיצור שאלון, שמירה ללא ריענון, עיצוב, PDF, חתימה מרחוק והיעדר תביעות. ההנחיה המאוחרת לקיצור שאלון גוברת על הרחבת 76 השאלות באפיון.

מטריצת enterprise-3.0-matrix.csv כוללת מופעי דרישות מהאפיון הקודם והחדש, עם שורות מקור ודרישות חוזרות; זו אינה ספירה של יכולות ייחודיות. NOT STARTED מציין שאין עדיין אימות מלא לפרט, גם אם קיים בסיס. אין לסמן TESTED על סמך קיום מסך בלבד. מצבי IN PROGRESS/IMPLEMENTED אינם מסירה מלאה. יש להעמיק את המיפוי עם כל מימוש נוסף.

## מימוש בסבב

שמירת רקע שאינה מחליפה שדות, שאלון גרסה 4 מקוצר, היעדר תביעות ואישור פטור אכשרה לפי גרסת מוצר, מנגנון קישור חתימה אישי עם hash/תוקף/ביטול/גרסת תוכן, שלושה מסמכים לחותם, חתימה ושמירת שלב 16 אטומית, מעקב בהסכמה והודעות עזרה בהרשאה נפרדת, עיצוב Back Office מעודכן, מסמכי A4 במיתוג ביטוחה, מרכז מסמכים, תור הפקת PDF עם lease/retry/קובץ קבוע/בדיקת שלמות, רישום הורדות, מהדורת חתימה נפרדת, 20 פעולות עסקיות ממומשות. מיגרציות 009 ו־010 תוספתיות; לא בוצע איפוס של נתוני העבודה.

## המשימה הבאה

המשך PHASE 2–4: קטלוג גרסאות Workflow וכללים מנוהלים במסד, קטלוג שאלונים מותנים לפי גיל/מין/גזע, תמחור מבוסס כללים וסביבת חיתום מעמיקה. בדוק קודם את שמירת הרקע גם בהקלדה במהלך בקשה שנעצרה ברשת, ואת הרשאות המסמכים והחתימה ברמת רשומה. לאחר מכן PHASE 5–9: תיקי פוליסה ותביעה, שינויים לפי תחולה, התחייבויות, ספר חשבונות כפול והתאמות. יתר פערי 2.0 ו־3.0 נשארים במטריצה; אין ליצור כפתורים לפעולות שטרם מומשו.

מסמכים עדיין דורשים קטלוג 35 תבניות, עורך תבניות מורשה, ארכוב/ביטול וגרסאות תבניות מנוהלות. מנוע ה־PDF הנוכחי שומר גרסת תבנית 1 ו־HTML קפוא. API החתימה הוא סימולציה ללא אימות זהות משפטי; אין לחשוף לאינטרנט לצורך שימוש אמיתי בלי להשלים את דרישות האבטחה והפרטיות. Windows טרם נבדק בפועל.

## פקודות

```sh
cd /workspace/bitucha
export npm_config_cache=/workspace/.npm-cache
docker compose --project-name bitucha-cloud --env-file /workspace/.setup/bitucha/.env -f /workspace/.setup/bitucha/compose.yaml up -d --wait
npm run db:migrate
npm run db:generate
npm run build
```

בדוק פורטים לפני הפעלת שרתים. API וממשק 3.0 בסבב הבדיקות פעלו בפורטים 3600 ו־5224, עם WEB_ORIGIN=http://localhost:5224 ו־API_PROXY_TARGET=http://127.0.0.1:3600. תהליכים אינם נשמרים בשחזור.

```sh
TEST_API_URL=http://127.0.0.1:3600/api/v1 npm test
npm run test:system
TEST_API_URL=http://127.0.0.1:3600/api/v1 TEST_WEB_URL=http://localhost:5224 npm run test:e2e
```

`test:system` מוחק רק מסד זמני חדש שיצר; אין לבצע reset על מסד העבודה או למחוק volumes. שמור `.env` מחוץ ל־Git. המשך בענף העבודה, לא ב־main. יש לבנות מחדש Docker לאחר שינוי קוד ולהריץ deployment-smoke.ts.
