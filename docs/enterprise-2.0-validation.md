# אימות סבב תהליכי הצטרפות ומנהלה

נבדק ב־9 באוקטובר 2026, בסביבת Linux בענן.

- `npm run build`: TypeScript strict ובניית Vite עברו.
- `TEST_API_URL=http://127.0.0.1:3300/api/v1 npm test`: 58 בדיקות עברו — 18 מנוע כיסוי, 17 API בסיס, 8 כללי הצטרפות, 9 API של תהליכי הצטרפות ו־6 API עובדים והרשאות.
- `npm run test:system`: עברו תהליכי איפוס/החזרת דוגמאות במסד זמני חדש בלבד: הרשאות, סיסמה ומשפט אישור, סירוב לתצוגה מקדימה מיושנת, אטומיות, שמירת עובדים והתחברות, מניעת כפילות, שימור שינויי משתמש, שמירת מצב ריק לאחר seed אוטומטי, והחזרה מפורשת לאחר איפוס.
- `npm run test:e2e`: דוח הריצה האחרונה מציין passed ללא בדיקות נכשלות. נבדקו שני מסלולים: מסלול הליבה הקיים; ואשף 18 שלבים, טיוטה ורענון, שאלונים, חתימה, הפקת פוליסה, 12 חיובים, חמישה מסמכים ו־PDF, פתיחת חידוש עם נתוני התקופה הקודמת, ויצירה ועדכון עובדים והרשאות מותאמות.
- בדיקות API נוספות מכסות שני כותבים מקבילים, גרסה מיושנת, ביטול השלמת שלבים כתוצאה מעריכה ללא מחיקת הגרסה המקורית, הפרדת יוזם/מאשר, אסמכתה רפואית מאושרת, הרשאות למסמכים, בריחת HTML, snapshot שאינו משתנה, חידוש דרך כל השלבים עם קישור לתקופה הקודמת ומניעת כפל, מחיר הרחבות וביטול לוח חודשי ללא זיכוי יתר.
- במהלך הפיתוח נתגלתה השוואת hash שתלויה בסדר מפתחות JSON. תוקנה באמצעות סדר קנוני, ומסלולי ההפקה עברו לאחר התיקון.
- תוקנו שמות נגישים לשדות select בעקבות כשל E2E ראשון. ריצות שנקטעו בזמן הפעלה מחדש של שרת הפיתוח הורצו מחדש לאחר התייצבות השרת; אין להסתמך על תוצאות הריצות שנקטעו.

בניית Docker של הגרסה הכוללת הצטרפות, איפוס, חידוש וניהול עובדים עברה; שלושת השירותים עלו ב־Compose, ונבדקו התחברות, PostgreSQL, PDF בקונטיינר וכניסה בדפדפן. מגבלת Nginx הותאמה ל־2MB ונבדקה: בקשת 1.4MB הגיעה לאימות API (401) במקום להיחסם בגבול Nginx (413). בדיקות הפריסה אימתו גם 16 פעולות עסקיות, קריאת עובדים עם גרסאות ללא passwordHash, ותצוגת איפוס מקדימה השומרת הרשאות עובדים. Windows טרם נבדק בפועל. פירוט הדרישות שעדיין חסרות מופיע ב־enterprise-2.0-progress.md; בדיקות אלו אינן אימות של כל האפיון.
