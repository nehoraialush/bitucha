# אימות סבב תהליכי הצטרפות ומנהלה

נבדק ב־9 באוקטובר 2026, בסביבת Linux בענן.

- `npm run build`: TypeScript strict ובניית Vite עברו.
- `node --env-file=.env node_modules/vitest/vitest.mjs run`: 51 בדיקות עברו — 18 מנוע כיסוי, 17 API בסיס, 8 כללי הצטרפות ו־8 API של תהליכי הצטרפות.
- `npm run test:system`: עברו תהליכי איפוס/החזרת דוגמאות במסד זמני חדש בלבד: הרשאות, סיסמה ומשפט אישור, סירוב לתצוגה מקדימה מיושנת, אטומיות, שמירת עובדים והתחברות, מניעת כפילות, שימור שינויי משתמש, שמירת מצב ריק לאחר seed אוטומטי, והחזרה מפורשת לאחר איפוס.
- `npm run test:e2e`: דוח הריצה האחרונה מציין passed ללא בדיקות נכשלות. נבדקו שני מסלולים: מסלול הליבה הקיים; ואשף 18 שלבים, טיוטה ורענון, שאלונים, חתימה, הפקת פוליסה, 12 חיובים, חמישה מסמכים ו־PDF.
- בדיקות API נוספות מכסות שני כותבים מקבילים, גרסה מיושנת, ביטול השלמת שלבים כתוצאה מעריכה ללא מחיקת הגרסה המקורית, הפרדת יוזם/מאשר, אסמכתה רפואית מאושרת, הרשאות למסמכים, בריחת HTML, snapshot שאינו משתנה, מחיר הרחבות וביטול לוח חודשי ללא זיכוי יתר.
- במהלך הפיתוח נתגלתה השוואת hash שתלויה בסדר מפתחות JSON. תוקנה באמצעות סדר קנוני, ומסלולי ההפקה עברו לאחר התיקון.
- תוקנו שמות נגישים לשדות select בעקבות כשל E2E ראשון. ריצות שנקטעו בזמן הפעלה מחדש של שרת הפיתוח הורצו מחדש לאחר התייצבות השרת; אין להסתמך על תוצאות הריצות שנקטעו.

בניית Docker ואימות הקונטיינרים יתווספו לאחר השלמתם. Windows טרם נבדק בפועל. פירוט הדרישות שעדיין חסרות מופיע ב־enterprise-2.0-progress.md; בדיקות אלו אינן אימות של כל האפיון.
